## 一、网页升级与定位转向

博客定位从 **CS 学习笔记** 转向 **个人主页**，CS 将作为子域之一。后续会加入读书笔记、经济学、个人思考等内容。为此需要对整个结构进行升级：

- **主页面**：添设图形化看板、个人近态等高度图形化展示，聚合各领域最新动态
- **子页面**：分别为 CS、读书、经济、科研等子领域设立独立板块，便于后续面试求职
- **技术演进**：逐步考虑独立主页，基于 JS/TS 规范重写，脱离 Jekyll 的纯静态模板限制

## 二、阅读与读书笔记

经济学和文学阅读的笔记形式会区别于计算机笔记——更偏向**个人随笔**而非详细知识整理。随手记录即可。

## 三、数模与科研

数学建模和科研相关内容开始纳入博客范围。

## 四、编辑流程优化

目前的编辑流程：

```
写 Markdown → 复制粘贴 → 改 front matter → commit → push
```

太繁琐。希望实现：

- **Obsidian 本地编辑**：用 Obsidian 管理本地文件夹，所见即所得
- **文件夹组织**：按领域分目录，而非全部塞在 `_posts/`
- **快速新建**：一行命令或 Obsidian 模板生成新帖，自动填充 date/title/category
- **一键部署**：Obsidian 改完 → 同步到仓库 → 自动推送部署

目标是把写博客的成本降到和写笔记一样低。
